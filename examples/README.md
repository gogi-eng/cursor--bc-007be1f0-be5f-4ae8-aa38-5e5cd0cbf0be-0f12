## Examples

This folder is intentionally lightweight and safe-by-default.

- Prefer using vendor SDK example folders directly when integrating:
  - CCXT WS examples live under `ccxt/ccxt/examples/ccxt.pro/py/` (upstream).
  - Hyperliquid SDK examples live under `hyperliquid-python-sdk/examples/` (upstream).
  - dYdX v4 examples live under `dydxprotocol/v4-clients/v4-client-py-v2/examples/` (upstream).

Add your own runnable scripts here (with env var based configuration) once you decide your venues.
